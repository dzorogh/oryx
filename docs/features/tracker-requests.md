# Tracker — Заявки (`/tracker/requests`)

Раздел **Заявки** в модуле Tracker: каталог видов заявок по отделам, форма подачи и «Мои заявки» со статусом, данными формы и обсуждением. Это чисто визуальный прототип: бэкенда нет, отправленные заявки и комментарии живут в памяти до перезагрузки страницы.

UX-макеты, из которых вырос экран: `_bmad-output/planning-artifacts/ux-designs/ux-tracker-requests-2026-10-14/mockups/` (`requests-v3.html` — утверждённый вариант).

## Маршруты

| URL | Назначение |
|-----|------------|
| `/tracker/requests?section=<id>&sub=<id>` | Каталог: дерево разделов слева, карточки видов заявок выбранного подраздела справа |
| `/tracker/requests/new/<typeId>` | Форма подачи заявки |
| `/tracker/requests/my?filter=active\|closed\|all&id=<id>` | Мои заявки: список и карточка выбранной заявки |

- Пункт **Заявки** в subnav Tracker: `src/features/tracker/tracker-nav.ts`.
- `app/tracker/requests/layout.tsx` оборачивает все три страницы в `RequestsProvider` (общее состояние заявок).

## Что видит пользователь

### Шапка

Белая карточка-тулбар (см. [list-page-toolbar.md](../conventions/ui/list-page-toolbar.md)) на всех трёх страницах: заголовок «Заявки» и переключатель **Каталог / Мои заявки** со счётчиком активных заявок. Переключение между каталогом и своими заявками живёт на странице, не в боковом меню. Справа — поиск (в каталоге — по видам заявок, в «Моих заявках» — по номеру и теме). В «Моих заявках» под разделителем — фильтры «Активные», «Завершённые», «Все».

### Каталог

- 7 разделов (IT, HR, Финансы, АХО, Юридический отдел, Закупки, Маркетинг), в каждом подразделы, в подразделе 2–4 вида заявок — всего 83 вида.
- Слева дерево: раскрыт текущий раздел, у подразделов число видов.
- Справа шапка подраздела (исполнитель и срок реакции) и карточки видов: название, описание, срок, число полей.
- Поиск ищет по всем словам запроса в названии, описании, подразделе и разделе (без учёта регистра и «ё») и показывает результаты с путём «Раздел · Подраздел».

### Форма

- Одна колонка, поля сверху вниз, два поля в одной строке не бывает. У каждого поля — название, необязательное описание серым, отметка `*` для обязательных.
- «Отправить заявку» проверяет обязательные поля: незаполненные подсвечиваются, страница прокручивается к первому. После отправки заявка получает номер `ЗВ-<n>`, появляется первой в «Моих заявках» и открывается.
- Файлы не загружаются: в форме и заявке видны только имена выбранных файлов.

### Мои заявки

- Слева спокойный список: заголовок (жирный — есть непрочитанное), время обновления, строка «цветная точка статуса · статус · номер · вид заявки».
- Справа карточка: статус, номер, заголовок, путь в каталоге, исполнитель, даты; если исполнитель ждёт ответа — нейтральная подсказка. Ниже **Данные заявки** (поля формы так, как их заполнили), под ними **Обсуждение** с системными событиями и комментариями и полем ответа (кроме отклонённых заявок).
- Кнопок «Отозвать» и «Повторить» нет.

## Конструктор форм

Форма вида заявки — список полей в `REQUEST_FORMS` (`src/features/tracker/requests/request-forms.ts`). Поле: `{ id, type, label, description?, required?, ... }`.

| `type` | Контрол | Доп. свойства |
|--------|---------|---------------|
| `text`, `textarea` | Строка / многострочный текст | `placeholder` |
| `number`, `money`, `date` | Число, сумма в ₽, дата | — |
| `period` | Две даты «с — по» | — |
| `select` | Выпадающий список | `options` |
| `radio` | Один из вариантов | `options`, `defaultValue` |
| `multi` | Несколько из вариантов | `options` |
| `person` | Сотрудник из демо-списка | `defaultValue` |
| `checkbox` | Флажок | — |
| `file` | Вложения (только имена файлов) | — |

Виды без своей схемы получают общую форму: тема, описание, срочность, вложения.
