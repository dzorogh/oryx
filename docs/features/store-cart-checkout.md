# Корзина и оформление заказа

Глобальная корзина менеджера и страница оформления `/store/checkout`: раскладка на черновики заказов клиента по способу **Склад региона** или **Производственная площадка**.

## Зависимости

- Контекст региона (`useSelectedRegion`, `RegionProvider` в корневом layout) — [store-pim-catalog.md](store-pim-catalog.md).
- Запасы «Готово · Всего» — тот же `computeVariantRegionStock`.
- Деньги заказа / floatrates — [logistics.md](logistics.md).

## Корзина

- Хранение: `localStorage` ключ `store-cart` = `[{variantId, quantity}]`, синхронизация между вкладками.
- Количество кратно `quantity_per_unit` (ввод округляется вверх; ≤0 удаляет строку).
- Кнопка в футере nav rail (над Settings) открывает шторку справа; «Оформить» → `/store/checkout`.
- В каталоге и на карточке товара тележка добавляет одну упаковку и превращается в счётчик `− N +`.

Файлы: `src/features/store/cart/*`.

## Оформление

Страница: `app/store/checkout/page.tsx` → `StoreCheckoutPage`.

Две карточки способа:

| Способ | Блоки | Цена | Источник заказа |
|--------|-------|------|-----------------|
| Склад региона | один блок = хаб региона | дилерская × (1 + Supply costs %/100); нет % → 0% | `hub` + `hub_warehouse_id` |
| Производственная площадка | блок на каждую площадку (код) | дилерская без наценки | `plant` + `plant_id` |

- Галочка строки → снятые уходят в свёрнутый «Остаются в корзине».
- У хаба при нехватке: подпись «N из наличия · M под заказ»; наценка на всё количество.
- Площадки/склады — только коды (префиксы из «Settings → Префиксы кодов», по умолчанию `PLT-n`, `WH-n`); слово «завод» не используется.
- Калькулятор контейнеров — в каждом блоке площадки: мультиселект типов, движок `packMixedContainers`, 3D-сцена с кодом типа и % заполнения. Негабарит — предупреждение, оформление не блокируется.
- «Оформить блок» / «Оформить всё» → RPC `store_checkout_customer_order` (черновик `draft`), валюта денег — `store_region.order_currency_id` (иначе дилерская). Созданные строки уходят из корзины; окно результата со ссылками / ошибками.

## Данные

Миграции:

- `store_product_variant_logistics`, `store_container_type`, `store_product_supply_cost`
- `store_product_variant.quantity_per_unit`, `store_region.order_currency_id`
- сид из `scripts/data/logistics-demo.json` через `scripts/generate-cart-checkout-seed.mjs`

Диалог региона (логистика): поле **Валюта заказов**.
