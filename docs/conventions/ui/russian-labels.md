# Русские подписи в интерфейсе

Весь пользовательский текст на страницах приложения должен быть на **русском**:

- Заголовки, хлебные крошки, кнопки, плейсхолдеры
- Заголовки колонок, пустые состояния, подсказки
- Подписи фильтров, статусы, aria-labels
- Сообщения об ошибках и валидации, которые видит пользователь

Не оставляйте английские названия разделов и контролов («Regions», «Ledger», «Filters»), если для них есть обычное русское слово.

Комментарии в коде и внутренние документы для разработчиков могут быть на любом языке. Коды документов (`REG-1`, `OMS-12`) и технические идентификаторы не переводятся.

## Примеры

```tsx
// Плохо
<TableHead>Name</TableHead>
placeholder="Search by name or SKU"

// Хорошо
<TableHead>Название</TableHead>
placeholder="Поиск по названию или коду"
```

Префикс цены у базовых товаров: `от` (например `от 11 990 ₽`), не `from`.

## Старый сканер английского UI

`npm run check:ui-english` и `npm run lint:ui-english` — наследие правила «только английский». Их не запускают как обязательную проверку и не используют, чтобы запрещать кириллицу.
