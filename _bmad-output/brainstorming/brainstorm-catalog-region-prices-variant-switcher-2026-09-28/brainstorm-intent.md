# Намерение

## Цель и пользователь
- Пользователь — менеджер продаж: сверить прайс, оформить заказ за клиента, ответить клиенту по цене или наличию.
- Смотреть цены, статусы и запасы любого региона, а не только текущего (как на бою).
- Удобно переключать варианты на карточке товара.

## Контекст региона
- Один регион за раз, без сравнения колонками.
- Регион меняет цены, статусы, наличие и остатки.
- Переключатель — поиск-комбобокс; у региона видны код, валюты и код хаба (`KZ · KZT/USD · WH-3`).
- Общий компонент и одно значение в localStorage для каталога, карточки и прайс-листов. Детали хранения для демо не важны.
- Размещение на уровне страницы: тулбар каталога; на карточке — строка над колонками, у хлебных крошек. Не у блока цен.
- Понятия «мой регион» нет. Без выбранного региона цены не показываются: в колонках цен и на карточке заглушка «Выберите регион» с кнопкой, открывающей переключатель.
- Валюта берётся из самой цены (дилерской и розничной): у каждой цены своя валюта, без пересчёта. Колонка может смешивать валюты, поэтому валюта показывается в каждой ячейке.
- Хаб региона задаётся настройкой региона; один хаб обслуживает несколько регионов.

## Запасы (общий блок «Готово · Всего»)
- **Готово к отгрузке** = свободно на хабе региона + резерв под регион на хабе региона.
- **Всего** = буквально всё: остатки на всех складах, в производстве и в пути, включая резервы под другие регионы. Из чего складывается — видно только в детализации.
- Числа нейтральные, без цветовой подсветки и подсказок о поступлении.
- Сводка — кнопка: клик открывает окошко (поповер) детализации для конкретного варианта.
- Детализация — таблица:
  - строки (места): хаб региона, склады производственных площадок, другие хабы (только коды мест);
  - колонки: свободно, резерв под регион, резерв всего, в производстве, в пути.

## Карточка товара
- Раскладка как на бою.
- **Левая колонка (узкая):** шапка товара (фото, название, число вариантов), вкладки Info/Description/Meta/Docs — поля товара общие для всех вариантов.
- Ниже — карточка «Варианты N»: кнопка добавления, «Показать архивные» и поиск по вариантам остаются как на бою.
- **Список вариантов** — узкая двухстрочная таблица:
  - строка 1: название + дилерская цена;
  - строка 2: точка статуса + «Готово · Всего»;
  - числа выровнены между строками; всё для выбранного региона.
- Клик по строке выбирает вариант; выбранный вариант отражается в адресе страницы (`?variant=`), ссылку можно отправить. При одном варианте (90% товаров) список остаётся из одной строки — экран одинаковый для всех. Обычно 2–8 вариантов, отличаются комплектацией или цветом.
- **Правая панель** — выбранный вариант целиком: фото, название, статусы Dealer/Retail, ID, SKU, Quantity per unit, цены Retail/Dealer, вкладки Attributes/Logistics/Competitors/Docs. При смене варианта меняется вся панель.
- Поле Stock в шапке варианта заменяется на «Готово · Всего» с окошком детализации.

## Каталог
- Строка таблицы — вариант. В ней ячейка «Готово · Всего» с тем же окошком детализации: менеджер отвечает клиенту, не открывая карточку.
- Цены в строке — по выбранному региону, с валютой в каждой ячейке; в сводных местах (строка варианта) — дилерская цена.

## Прайс-листы
- Только замена текущего Select на общий переключатель региона (то же значение в localStorage).
- В режимах без региона (`scopeHasRegion` = false) переключатель скрыт, сохранённое значение не сбрасывается.
- Блок запасов не добавляется.
- Образец для переключателя и детализации — готовый выбор и раскрытие регионов в прайс-листах (`pricelists-expanded-regions`).

## Техническая основа
- **Фундамент:** `loadDbCatalogItems` игнорирует `region_id` — сейчас в каталоге цены случайного региона. Нужен фильтр цен `store_product_price` по `region_id` (в БД dealer+retail по 10 регионам: ae, ru, kz, by, uz, mx, de, us, in, om; purchase без региона).
- Одна функция расчёта «Готово/Всего» и детализации на пару вариант + регион — общая для строки каталога и строки списка вариантов.
- Два общих компонента: поиск-переключатель региона и блок «Готово · Всего» с окошком детализации; каталог, карточка и прайс-листы — потребители.
- Нужна настройка «хаб региона» (сейчас в сиде только Dubai Hub) — привязать к нему несколько регионов.
- Нужны демо-данные запасов: хабы, склады производственных площадок, резервы (под регион и всего), в производстве, в пути.
- Сейчас есть demo-карточка `bike-*` с `VariantMenu` и отдельная логистическая карточка из БД (`catalog-pages.tsx`) — учесть при выборе, что переделывать.

## Вне объёма
- Оформление заказа из детализации запасов и регион заказа — отдельной сессией.
- Сортировка и фильтр по цене при смешанных валютах (в будущем — внутри одной валюты).
- Сравнение регионов колонками; пересчёт в базовую валюту.
- Бейдж «чужой регион / вернуть мой».
- Подсветка «Готово» цветом и подсказка о ближайшем поступлении.
- Запасы в прайс-листах.
- Обратный выбор (Готово N у регионов в переключателе).
- Переключатель региона в шапке всего раздела Store & Catalog; переключатель у блока цен.
- Удаление поиска по вариантам; пятиколоночная таблица вариантов.
- Конвейер слева направо и раскрытие матрицы под строкой (варианты C и A).
