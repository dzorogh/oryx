# Заказ клиента: что есть на проде (my) и нет в Oryx

Дата: 2026-10-13. Прод — `origin/main`: `~/my-front` `3f29bffd2`, `~/my-back` `d8754a78ff`. Oryx — `main` после `c1913bb`.

## Вкладка «Логистика» на проде

Вкладки карточки на проде: «Финансы», «Логистика», «Файлы и комментарии», «Метаданные».

**Поставщик**

- «Склад поставщика» — код склада, ссылка на справочник; менеджер выбирает селектом.

**Маршрут** — выбирается из справочника `pim_routes`, остальные поля только показ:

| Поле | Откуда данные |
|---|---|
| Маршрут | `route.name`, селект |
| Откуда | склад компании маршрута: город, иначе название |
| Куда | площадки маршрута: город, иначе код, через запятую |
| Вид транспорта | флаги: Железнодорожный, Автомобильный, Морской, Воздушный |
| Стоимость за куб | `approx_cost_per_cubic` + валюта |
| Время в пути | `transit_days`, «N дней» |
| Стоимость за 40' контейнер | `approx_cost_per_container_40`, USD |

**Отслеживание заказа** — лента смен статуса: статус и дата.

**Скрыто на проде (MY-2265):** импортёр, дата бронирования, таможенное оформление, транспорт, брокер (у каждого стоимость, валюта, дата оплаты).

В Oryx нет маршрутов, видов транспорта и стоимостей доставки. «Склад поставщика» у нас — источник в шапке, «Отслеживание» — вкладка «История».

## Остальное, чего нет в Oryx

| Блок | На проде | В Oryx |
