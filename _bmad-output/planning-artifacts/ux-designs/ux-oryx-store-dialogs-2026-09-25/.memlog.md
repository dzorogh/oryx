- (decision) Источник: brainstorm-store-dialogs-redesign-2026-09-25. Эталон — «Запустить производство». Четыре типа: A каталожная модалка ~90vh, B строки контекста md/lg, C компактная форма, D подтверждение.
- (decision) Оболочка: надзаголовок, заголовок, реквизиты одной строкой, тело, липкий футер с итогом и глаголом-последствием. Склады и заводы — только коды. Строка = таблица, не мини-форма. Жёсткий лимит подсвечивает «максимум N» и не режет ввод. Мягкий — «сверх остатка N».
- (event) Пользователь попросил прототипы визуалов четырёх типов окон.
- (event) Прототипы в .working: key-transfer, key-customer-order, key-production, key-compact. Спайны DESIGN/EXPERIENCE ещё черновики.
- (decision by user) Реквизиты в шапке — редактируемые поля, а не текст. Перемещение: «Со склада» → «На склад» и «Ожидаемое окончание» (необязательно).
- (decision by user) Владелец виден в каждой строке ввода: отдельная колонка «Владелец» (Свободно / CO-N заказ клиента / регион). Один владелец — чип в строке товара; несколько — «N владельцев» и подстроки. Выбор владельца = ввод количества в его строку.
- (decision by user) Каталожная модалка: реквизиты документа (откуда, куда, срок) — белая шапка с полями обычного размера. Управление списком (поиск, свернуть, только выбранные, заполнить) — отдельная серая панель «Товары · остаток на WH-N» над таблицей, мелкие контролы 28px, кнопки без обводки. Не смешивать.
- (override by user) Отменена отдельная колонка «Владелец». Возврат к подстрокам: несколько владельцев — подстроки с меткой владельца в первой ячейке; один владелец — метка под названием товара, поле в той же строке.
- (override by user) Подстроки владельцев у каждого товара, даже при одном владельце. Строка товара: название, код, «· N владельцев», общий остаток, без поля. Поле количества только в подстроке владельца.
- (decision by user) Без счётчика «N владельцев» в строке товара — число подстрок и так видно.
- (override by user) Кнопка «Заполнить всем остатком» не нужна — убрана из перемещения (и массовое заполнение из витрин в целом).
- (decision by user) Заголовок панели таблицы — просто «Товары», без «остаток на WH-N»: источник уже выбран в шапке. Общее правило: не дублировать подписью то, что видно из полей и структуры.
- (override by user) Новый заказ клиента (хаб): остатки — три отдельные колонки «На хабе» (жирно) | «В мире» | «В резерве» (приглушённо), а не одна ячейка «крупно на хабе, мелко в мире · в резерве».
- (change) Новый заказ клиента приведён к виду перемещения: реквизиты полями с подписями (Источник, Хаб, Срок) в белой шапке, серая панель «Товары» с поиском / свернуть / только выбранные над таблицей. Типы B/C/D панели не имеют — нечего разделять.
- (decision by user) Тип склада: склад завода / склад-хаб / склад покупателя (вместо флага хаба). Хаб в демо — только Dubai Hub. PO: подсказки «На складе завода» и «Уже производится». Источник заказа показывается в шапке заказа; план не предзаполняется.
