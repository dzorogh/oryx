- (decision) Coaching path: сначала варианты спорных мест, выбор пользователя, затем финальный макет
- (decision) Финальный прототип кликабельный: один HTML с демо-данными (фильтры, спрос, группы, меню «+», диалог) — осознанное отступление от «no JS» в key-screens по запросу пользователя
- (event) Спорное место A: как показать спрос рядом с приходом в ячейке месяца — варианты: две строки в ячейке / подстрока «Спрос» под товаром / парные подколонки Приход|Спрос
- (event) Спорное место B: форма фильтра владельцев — одна кнопка-поповер «Считаем: …» / чипы в тулбаре / боковая панель с двумя списками (приход и спрос)
- (event) Спорное место C: подача дерева категорий — вложенные строки групп с отступом / плоские группы с путём «ATV → 4x4» / корень лентой-разделом, дочерние — строками групп
- (event) Демо-данных для календаря в живой базе мало (4 черновика выпусков, почти без сроков; выпуск со сроком 1941-12 — артефакт сида): прототип использует вымышленные выпуски/заказы поверх реальных товаров, категорий, заводов, регионов
- (decision) Спрос убран из задачи: спорное место A снято; в B остаётся только фильтр прихода (вариант B3 с вкладками Приход/Спрос теряет смысл вкладок)
- (decision) Пометку «также в: …» у товара не показываем
- (decision) B3: фильтр «Для кого считаем» — правая боковая панель (без вкладок, только приход)
- (decision) «С заказами клиентов региона» — переключатель (switch), не чекбокс
- (decision) C1: дерево категорий — вложенные группы с шевронами и отступами
- (event) Прототип key-calendar.html проверен в браузере: дерево C1 сворачивается, панель B3 пересчитывает остаток и месяцы, фильтр завода сужает список (105→23 строки), меню «+» и диалог создают выпуск с датой последнего дня месяца
- (event) Несостыковка: новый выпуск из ячейки создаётся «Свободно»; при снятом «Свободно» в фильтре он не виден, подсвечивается пустая ячейка — нужно решение
- (event) Доработки: в диалоге показать товар и PO; количество по умолчанию = «осталось разложить»; строка «Считаем» при всех регионах — «все регионы» вместо перечня
- (decision) Созданный из ячейки выпуск сразу добавляется в таблицу, даже если фильтр владельцев его исключает; при обновлении данных страницы (перезагрузке) он подчиняется фильтру и может пропасть
- (decision) В панели «Для кого считаем» — кнопки «Все регионы» и «Все заказы»
- (decision) Приняты без возражений: в диалоге товар и PO; количество по умолчанию = «осталось разложить»; «все регионы» в строке «Считаем»
