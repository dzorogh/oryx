## Intent

**Problem:** Текущее окно создания заказа на производство смешивает редактируемые и справочные данные в плотной таблице, заставляет пользователя самостоятельно оценивать результат операции и плохо масштабируется на длинные списки товаров.

**Approach:** Реализовать выбранный вариант C: адаптивный двухпанельный планировщик, где слева редактируются производитель, срок и количества, а справа в реальном времени показывается компактное резюме создаваемого заказа и степень покрытия потребности. На узких экранах панели складываются вертикально; существующая бизнес-логика создания и резервирования сохраняется.

</frozen-after-approval>

## Implementation Notes

- Основной файл: `src/features/logistics/order-action-forms.tsx`, компонент `ProductionFromOrderForm`.
- Сохранить вычисление доступных производителей, повторное заполнение количеств при смене производителя, ограничение диапазона, формирование `payload`, `createProductionForOrder` и сброс при открытии.
- Переиспользовать `LogisticsDialog`, `FieldSelect`, `ExpectedEndField`, `ProductIdentity`, существующие balance helpers и UI primitives.
- Работать поверх текущего незакоммиченного WIP с явного разрешения пользователя; не отменять и не переписывать смежные изменения.
- Новые пользовательские подписи должны быть на английском по конвенции проекта.
- Реализована сетка 1.12/0.88: редактор параметров и карточек товаров слева, sticky live preview справа; ниже `lg` панели складываются вертикально.
- Итог не суммирует разнородные единицы измерения: показывает число выбранных товарных строк и количества внутри каждой строки.
- Покрытие считается по всем открытым строкам заказа, поэтому несовместимые с выбранным производителем товары корректно оставляют статус partial coverage.
- Изменён `src/features/logistics/order-action-forms.tsx`; API и правила формирования payload не менялись.
- Браузерная проверка подтвердила desktop/mobile компоновку, заполнение количеств, реактивное резюме, дату и отсутствие горизонтального переполнения.
- 2026-09-18: пользователь выбрал вариант A вместо C. UI двух панелей заменён компактной таблицей; продолжение в `spec-production-order-dialog-compact-table.md`.
