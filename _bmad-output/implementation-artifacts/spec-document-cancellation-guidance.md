## Intent

**Problem:** Проведённые складские документы нельзя безопасно откатывать, но интерфейс не объясняет причину и не помогает выполнить обратное действие.

**Approach:** На карточках активных документов добавить видимое действие «Отменить». Для уже изменившего остатки документа оно открывает общий помощник с понятным объяснением, примером отрицательного остатка и доступными компенсирующими действиями; для безопасного черновика запускает подтверждаемую статусную отмену.

## Boundaries & Constraints

**Always:**
- Общий текст объясняет: система учитывает количества без серий и партий; после других движений нельзя определить исходные единицы; удаление старых проводок способно создать отрицательный остаток.
- Общий пример: выпуск добавил 10 единиц, 8 переместили, осталось 2; удаление исходных `+10` даст `−8`.
- Открытие помощника ничего не меняет. Каждое исправление создаёт новый предметный документ и сохраняет исходную историю.
- «Отменить» находится в тулбаре карточки, а не прячется в overflow. Для закрытого или уже отменённого документа действие скрыто.
- Безопасная настоящая отмена доступна только состояниям без проводок, которые уже поддержаны доменом: черновик отгрузки, черновик возврата и запланированный выпуск. Перед отменой показывается подтверждение.
- Контекстные действия используют существующие формы и проверки доступности.

**Never:**
- Не удалять, не изменять и не инвертировать старые факты журнала.
- Не отменять проведённый резерв, отгрузку, возврат, завершённый выпуск, отправленное/доставленное перемещение или корректировку.
- Не добавлять отмену черновика резерва и новые статусы сущностей в рамках этой работы.
- Не выполнять каскадную отмену связанных документов.

## I/O & Edge-Case Matrix

| Документ / состояние | Действие помощника | Результат |
|---|---|---|
| Проведённый резерв | Снять резерв / зарезервировать снова / переназначить | Открывается Reservation с обратным направлением и текущими лимитами |
| Проведённая отгрузка | Создать возврат | Открывается существующая форма возврата |
| Проведённый возврат | Зарезервировать снова | Открывается форма резерва свободного возвращённого товара |
| Перемещение отправлено | Отметить доставленным | После фактической доставки можно оформить обратное перемещение |
| Перемещение доставлено | Создать обратное перемещение | Открывается форма с переставленными складами |
| Выпуск завершён | Создать корректировку | Открывается корректировка текущего свободного остатка |
| Корректировка проведена | Создать корректировку | Открывается новая противоположная операция без изменения исходной |
| Заказ клиента открыт | Закрыть заказ | Текущие резервы освобождаются, отгруженное и связанные документы сохраняются |
| Заказ на производство активен | Закрыть заказ | Резервы снимаются, остаток незавершённого производства удаляется, выпуски сохраняются |
| Безопасный черновик | Подтвердить отмену | Меняется только статус; проводки не создаются |

**Acceptance Criteria:**
- Given проведённый складской документ, when пользователь нажимает «Отменить», then проводки не меняются и открывается объяснение с доступным обратным действием.
- Given черновик без проводок, when пользователь подтверждает отмену, then меняется только статус документа.
- Given закрытый или отменённый документ, when карточка открыта, then действие «Отменить» отсутствует.
- Given заказ клиента или производства, when открыт помощник, then он подробно описывает эффект закрытия и не обещает откат связанных документов.
- Given обратное действие недоступно из-за текущего остатка, when помощник открыт, then он объясняет необходимый предыдущий шаг вместо выполнения небезопасной операции.

## Design Notes

Помощник — образовательный маршрутизатор, а не новая складская операция. Основная кнопка внутри диалога называется по реальному действию («Создать возврат», «Снять резерв», «Закрыть заказ»), а «Закрыть» закрывает только диалог.
