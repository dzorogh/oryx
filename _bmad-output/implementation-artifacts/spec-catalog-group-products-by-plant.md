## Intent

**Problem:** В `/store/pim/products` варианты идут плоским списком: площадка только в колонке, товары одной площадки не собраны вместе.

**Approach:** После фильтров группировать строки по коду площадки со сворачиваемым заголовком. Оба режима списка группируются одинаково.

## Boundaries & Constraints

**Always:**
- Группировка всегда включена.
- Ключ — `productionSite`. В заголовке только код. `"—"` → «Без площадки» в конце.
- Коды по числовому порядку (`PLT-2` перед `PLT-10`). Внутри группы порядок `id` из загрузчика.
- Заголовок: шеврон и `pluralTovar(n)` по всей группе. Клик сворачивает одну группу. В тулбаре «Свернуть все» / «Развернуть все».
- Строка — один вариант. Режимы отличаются только ценой «от …» и кнопкой покупки.
- Фильтр площадки оставляет одну группу. При загрузке — скелетоны без заголовков. Колонки, регион, цены и остатки без смены смысла.
- Решение: без страниц. Все отфильтрованные строки в одном скролле фиксированной высоты. Шапка и заголовки площадок прилипают. Футер с номерами и «Показано N из M» уходит.

**Never:** название площадки; корзина, карточка, демо `bike-*`, схема БД, колонки по умолчанию; дерево категорий; импорт `ListTable`; свёртка в URL или localStorage.

## Implementation Notes

- Группировка живёт в `catalog-site-groups.ts` и реэкспортируется из `catalog-helpers.ts`. Таблица — сырой `table` внутри `overflow-auto`, иначе sticky ломает обёртка `ui/Table`.
- `catalogTableSection` решает скелетоны / пусто / группы и покрывает строки матрицы про загрузку и пустой список. Тесты: 6/6.
- Футер пагинации снят со страницы каталога. `catalog-footer.tsx` остаётся: им пользуются прайс-листы, `PAGE_SIZE` тоже.
- В демо коды площадок `SH-n` (префикс из настроек). В браузере на `localhost:3001`: группы по порядку, SH-2 перед SH-10, свёртка одной и всех, пустой поиск без заголовков, режим «Товары» с «от» и без покупки, страниц нет, заголовок группы прилипает под шапкой.
- `npm run lint` по репозиторию падает на четырёх старых ошибках в tracker/comments, не в этом diff. Eslint по файлам каталога, typecheck и check:docs — без ошибок.
- В рабочем дереве рядом лежат чужие правки `store-product-card-page.tsx` и `spec-fix-stock-cart-overlap.md`. К этой спеке они не относятся.
- После ревью свёртка вынесена в `toggleCatalogSiteCollapsed`, `catalogSiteKeysForCollapseAll`, `areCatalogSiteGroupRowsVisible` (тесты 9/9). Опции фильтра площадки сортируются `compareCatalogSiteKeys`. Typecheck после патча зелёный.
