## Intent

**Problem:** Каталог `/store/pim/products` скачивает все товары и рисует каждую строку. Поиск и фильтры режут уже скачанный массив.

**Approach:** Порции с бэка и виртуальный скролл. Поиск и фильтры уходят в запрос. В DOM только окно строк. Группы, свёртка и прилипающий код площадки остаются.

## Boundaries & Constraints

**Always:**
- Решение: первая порция сразу, следующая — у конца загруженного. Смена поиска, фильтра или региона сбрасывает список.
- Поиск (название и код) и фильтры (категория, семейство, площадка, статусы дилера и розницы) выполняет запрос к демо-Supabase. Статусы и цены — выбранного региона. Без региона цены — «Выберите регион», фильтр статуса ничего не отсекает.
- Категория — `store_category` / `store_product_category`, семейство — `store_product.family_id`. Угадывание по названию для фильтра и колонок больше не источник.
- Порядок: площадка, без площадки в конце, затем id. Счётчик группы — полное число в текущем фильтре, не только уже скачанные строки.
- Свёрнутая группа — в виртуальном списке только заголовок. Под шапкой прилипает код площадки у верхнего края. Высота строки измеряется.
- Первая порция — скелетоны. Следующая их не ставит вместо списка. Пустой ответ — прежний текст. Цена «от …» и покупка как сейчас.

**Never:** название площадки; корзина; карточка; демо `bike-*`; изменение таблиц и данных; колонки по умолчанию; свёртка в URL или localStorage.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Две площадки | `PLT-2` (2), `PLT-10` (1) | Заголовок, 2 строки, заголовок, 1 строка | N/A |
| Свёртка | `PLT-2` свёрнута | Заголовок есть, её строк нет | N/A |
| Конец списка | Есть ещё на бэке | Дописывается порция, старые строки остаются | Ошибка не затирает список |
| Фильтр | Новый поиск или статус | Запрос с первой порции, чужих товаров нет | Пусто — пустой текст |

**Acceptance Criteria:**
- Given длинный каталог, when список открыт, then в DOM нет далёких строк, а с сервера пришла только первая порция.
- Given есть ещё данные, when доскроллить до конца, then приходит следующая порция и старые строки на месте.
- Given поиск или фильтр, when его сменить, then список с первой порции и без товаров вне условия.
- Given свёрнутая группа, when прокрутить, then её товаров нет, код площадки под шапкой. Смена режима не меняет цену «от …» и покупку.

## Implementation Notes

- Порция 48 строк, порядок `plant_id` затем `id`. Счётчики групп считаются по всем `plant_id` текущего фильтра, не по скачанным строкам.
- Виртуальный список — `@tanstack/react-virtual`. Полоска активной площадки `z-30` с непрозрачным фоном; строки товаров в `z-0`, чтобы не просвечивали.
- Ошибка следующей порции не очищает список и показывает «Не удалось загрузить ещё».
- В браузере на `localhost:3001`: в DOM только видимые группы, прокрутка догружает (высота скролла выросла), закреплённый `SH-5` перекрывает строки.
- Семейства в демо могут быть пустыми (`family_id` не заполнен) — фильтр тогда без вариантов.
- Тесты `catalog-site-groups` 15/15, typecheck и check:docs зелёные.
