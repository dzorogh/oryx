## Intent

**Problem:** 12 списков Store (всё, кроме «Товары» и «Прайс-листы»: заказы клиента, отгрузки и возвраты, резервы, заказы на производство, выпуски, остатки, перемещения, корректировки, журнал, склады, регионы, заводы) собраны вручную и по-разному. У них только чипы статуса, нет поиска, фильтров, сортировки, группировки и управления колонками. В заказах клиента колонки «Занято / Отгружено / Открыто к резерву» непонятны. В выпусках нет завода. Количество в колонке «Товары» прижато к правому краю и выглядит как отдельная колонка.

**Approach:** Один общий каркас списка: шапка в стиле прайс-листов, декларативная таблица с сортировкой по клику на заголовок и сворачиванием колонки в узкую полоску, шторки «Фильтры» и «Колонки» (как в прайс-листах) и выбор группировки. Настройки колонок, сортировки и группировки сохраняются по каждому списку. Все 12 списков переводятся на этот каркас, каждому подбирается свой набор колонок, фильтров, сортировок и группировок.

## Boundaries & Constraints

**Always:**
- Шапка повторяет `PricelistsToolbar`: `Card size="sm"`, заголовок `text-lg`, основная кнопка справа, разделитель. Во второй строке: `ToggleGroup variant="outline"` для главной оси (статус или тип), поиск, 1–2 быстрых селекта, затем иконки `SlidersHorizontal` (Фильтры), `Columns3` (Колонки) и сортировка/группировка. У кнопки-иконки `variant="default"`, если есть отклонение от дефолта. У каждой иконки есть тултип и `aria-label`.
- Колонки: скрыть/показать в шторке «Колонки» (порядок фиксирован; колонка «Номер»/«Код» закреплена) и свернуть кнопкой в заголовке в полоску шириной около 2rem с вертикальной подписью; клик по полоске разворачивает колонку. Дефолт и сброс — в шторке. Всё хранится в `localStorage` по ключу списка.
- Товары в ячейке: количество стоит сразу после названия (`Название · 12 шт`), без `justify-between`.
- Склады и заводы вне своих справочников показываются только кодом (`place-codes.md`). Весь текст на русском.
- Группировка: строка-заголовок группы с подписью, числом документов и суммой количества; группу можно свернуть.
- Существующие параметры URL (`?direction=` у отгрузок, `?operation=` у резервов, фильтры остатков) продолжают работать.

**Never:**
- Не трогать «Товары», «Прайс-листы» и карточки документов (кроме общих компонентов, если правка их не ломает).
- Не добавлять серверную пагинацию или фильтрацию. Список фильтруется на клиенте, журнал сохраняет клиентскую пагинацию.
- Не менять бизнес-логику резервов, отгрузок и прочих операций.

**Decisions (человек, 2026-09-23):**
- «Код производства» в выпусках — это код завода `PLT-N`: отдельная колонка «Завод» со ссылкой. Нужна миграция `plantId` в `store_output_list`.
- В заказах клиента вместо «Занято / Отгружено / Открыто к резерву» три колонки с понятными названиями и тултипами: «Отгружено», «В резерве», «Не обеспечено» (= заказано − отгружено − в резерве). Плюс «Заказано».
- Колонка и фильтр «Автор» во всех документах; `createdBy` (имя) добавляется в list-RPC миграцией.
- Спека остаётся одной, без разделения.
- Прототип `_bmad-output/planning-artifacts/ux-designs/ux-store-lists-2026-09-23/mockups/store-lists.html` (итерация 2) — эталон. Шапка: вариант A (сортировка, группировка, фильтры, колонки — иконки справа). Товары: вариант A («Название · 12 шт»).
- Колонка товаров не уже 280px (резервы — 340px), названия не рвутся по словам; при нехватке места таблица прокручивается по горизонтали.
- Сворачивание колонки — кнопкой «‹» при наведении и через меню по ПКМ на заголовке (сортировка ↑/↓, свернуть/развернуть, скрыть, «Развернуть все»). Свернуть можно любую колонку, включая «Номер»; скрыть «Номер» нельзя.
- Заголовки без иконок-значков: пояснение колонки — компонент `Tooltip` (не нативный `title`) на названии с пунктирным подчёркиванием, появляется сразу при наведении. Кнопка «‹» появляется при наведении поверх заголовка (`absolute`, не влияет на ширину колонки и положение подписи): всегда у правого края заголовка, поверх подписи (`z-index` выше подписи и её тултип-триггера). У числовых колонок (выравнивание вправо) подпись и стрелка сортировки (стоит слева от подписи) совпадают по правому краю с числами.
- Никаких «пояснительных» подписей-заполнителей к экранам, шторкам и формам (описания под заголовками, `SheetDescription` вида «Отберите документы…», вводные фразы). Только заголовок и поля; `SheetDescription` — `sr-only`, если нужен для доступности. Тултипы — только у колонок с неочевидным расчётом.
- Свёрнутая колонка: узкая полоска (~28px) с иконкой `<>` (chevrons-left-right) в заголовке, высота шапки не меняется; при наведении тултип с названием колонки; клик — развернуть.
- Меню сортировки: сначала выбирается поле, ниже — направление отдельными кнопками; подписи по типу поля (даты: «Сначала старые/новые», числа: «По возрастанию/убыванию», текст: «А → Я / Я → А»). Для даты при выборе поля по умолчанию «сначала новые».

## Design Notes

Наборы (колонки → фильтры → сортировки → группировки; `*` — скрыто по умолчанию):
- **Заказы клиента:** Номер, Статус, Товары, Заказано, Отгружено, В резерве, Не обеспечено (оранжевое, если > 0 у открытого заказа), Срок (красный бейдж «просрочен N дн.»), Создан, Описание*, Автор* → статус (toggle), поиск (номер, товар, описание), товар, срок (просрочен / 7 дней / без срока), «есть необеспеченное», автор → создан, срок, номер, не обеспечено → статус, срок.
- **Отгрузки и возвраты:** Номер, Тип, Заказ клиента, Склад, Товары, Кол-во, Дата, Автор* → тип (toggle), склад, заказ, товар, период → дата, номер, кол-во → тип, склад, заказ клиента.
- **Резервы:** Номер, Операция, Назначение, Товары (с источником в строке), Место (вид + код), Статус, Создан → операция (toggle), статус, вид места, вид назначения, товар → создан, номер → место, назначение, операция.
- **Заказы на производство / Выпуски:** Номер, (Заказ на производство), Завод, Товары, Кол-во, Статус, Срок, Создан → статус (toggle), завод, просрочен, товар → создан, срок, номер → завод, статус, (заказ на производство).
- **Перемещения:** Номер, Откуда, Куда, Товары, Кол-во, Статус, Срок, Создан → статус, откуда, куда, просрочен → создан, срок → маршрут `WH-1 → WH-3`, статус, откуда.
- **Корректировки:** Номер, Операция, Склад, Товары, Изменение (со знаком, цветом), Описание*, Дата → операция (toggle), склад, товар → дата, изменение → склад, операция. Фейковые статус-табы убрать.
- **Журнал:** Время, Изменение, Товар, Место, Закреплено за, Документ → тип документа (select), товар, вид места, приход/расход, период → время, изменение → документ, товар, день (пагинация 20 строк внутри отфильтрованного списка; при группировке пагинация идёт по строкам).
- **Склады / Заводы / Регионы:** Код, Название, связь (Завод/Склад) → поиск; у складов тип (заводской / самостоятельный) → код, название → у складов тип.

Сворачивание колонки: `<th>` шириной ~28px с иконкой `ChevronsLeftRight` и `Tooltip` с названием колонки, ячейки пустые с `bg-muted/40`, у `aria-label` заголовка — «Развернуть колонку «…»».
