# Правила расчёта

Все числа — в штуках (`formatQuantity`), по варианту товара. У каждого товара в демо ровно один вариант.

## Владельцы и фильтр прихода

- Владелец количества: «Свободно», регион или заказ клиента. Это `store_stock_owner` у остатка и владелец строки выпуска.
- Фильтр задаёт множество владельцев **W** = {Свободно?} ∪ {выбранные регионы} ∪ {заказы клиентов выбранных регионов, если стоит галочка «с заказами региона»} ∪ {выбранные заказы клиента}.
- Количество попадает в ячейку, если его владелец входит в **W**. Каждое количество учитывается один раз, даже если владелец попал в **W** несколькими путями.
- По умолчанию **W** = все владельцы. Можно снять «Свободно» и оставить только резервы.
- Строка «Считаем: …» перечисляет состав **W** и фильтр «Завод».

## «Остаток»

- Сумма `store_stock_balance` по товару для мест вида «склад» (включая склады заводов) и «перемещение», по владельцам из **W**.
- Места «заказ клиента» (отгружено) и «заказ на производство» (устаревшие резервы) не входят.
- Фильтр «Завод» на остаток не действует.

## Приход (ячейка месяца)

- Строки выпусков в статусах `draft` и `in_progress`, по владельцам строки из **W**.
- Месяц — это год-месяц `expected_end_on` выпуска. Если срок пустой, количество идёт в «Без срока».
- Выпуски `done` и `cancelled` не учитываются.
- Завод выпуска — это завод его заказа на производство. Фильтр «Завод» оставляет только выпуски этого завода.

## Колонка «Код завода»

- Уникальные коды заводов из выпусков товара в статусах `draft` и `in_progress`, отсортированные. Если выпусков нет — «—».

## Категории

- `store_category` — дерево через `parent_id`. `store_product_category` — явные привязки, товар бывает и в корневой, и в дочерней категории.
- Товар без привязок попадает в группу «Без категории».
