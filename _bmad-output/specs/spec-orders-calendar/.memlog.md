topic: Календарь заказов/отгрузок (приход выпусков и спрос по месяцам) в Store Logistics
updated: 2026-09-24T11:42
---

- (direction) Источник: журнал брейншторма brainstorm-orders-shipments-calendar-2026-09-24; режим express — вход богатый
- (decision) Slug orders-calendar по названию пользователя
- (capability) CAP-1 Матрица товар × месяц: остаток и приход из выпусков «Черновик»/«В работе» по сроку выпуска
- (capability) CAP-2 Группировка по дереву категорий; товар во всех явно привязанных категориях; строка группы — название и число товаров
- (capability) CAP-3 Фильтр владельцев прихода: Свободно + регионы (+ заказы региона) + заказы клиента, объединение множеством; действует на остаток и месяцы; строка «Считаем: …»
- (capability) CAP-4 Фильтр «Завод» и колонка «Код завода» (все заводы выпусков товара)
- (capability) CAP-5 Спрос по переключателю, свой фильтр той же формы; без баланса
- (capability) CAP-6 Просрочка: прошлые месяцы с ранней просрочки, подсветка текущего месяца и непустых прошлых ячеек; колонка «Без срока»
- (capability) CAP-7 Быстрое создание из ячейки: выпуск по заказу на производство или новый заказ + черновик выпуска; диалог с датой = последний день месяца
- (constraint) Месяц — только срок выпуска; срок заказа на производство не используется
- (constraint) «Готов» и «Отменён» выпуски вне месяцев — готовое уже в остатке
- (constraint) Остаток = склады + склады заводов + перемещения; место «заказ клиента» не входит
- (constraint) Нет сумм в группах, нет общего итога, нет накопленных сумм, нет баланса приход−спрос
- (constraint) Горизонт: до месяца самого позднего выпуска, не меньше 6 месяцев вперёд
- (constraint) Конвенции Oryx: list-page-toolbar, full-width, place-codes (только коды заводов), русские подписи, одна read-RPC на страницу, anon только SELECT + command RPC
- (assumption) Спрос = Заказано − Отгружено по строке; месяц — срок заказа клиента; отменённые не считаются — предложено коучем, не опровергнуто
- (assumption) Маршрут /store/logistics/calendar, пункт меню в группе «Производство»
- (assumption) Фильтр спроса: регионы (+ заказы региона) и заказы клиента, без «Свободно»
- (question) Название экрана: «Календарь заказов/отгрузок» не совпадает с содержимым (приход выпусков + спрос)
- (question) Скрин Notion не получен — визуальная сверка не проведена
- (event) Pass 1 coherence: 7 CAP с intent+success, ограничения отсекают варианты, 5 non-goals, success signal демонстрируем — pass
- (event) Pass 2 preservation: все decision by user из брейншторма в SPEC/компаньонах; неподтверждённые предложения коуча — в Assumptions; отброшены процессные записи (техники, недоступность скрина кроме open question) — pass
- (decision) Название экрана «Календарь выпусков»: слово «календарь» от пользователя, «выпуски» — термин Oryx для прихода; спрос — опциональный слой по переключателю
- (decision) Сверка со скрином Notion не нужна — вопрос снят пользователем
- (decision) Спрос полностью убран из задачи и реализации — интерфейс слишком сложный. CAP-5 снята (ID не переиспользуется); допущения о спросе и фильтре спроса удалены; «где не успевают» = только просрочка выпусков
- (decision) Пометку «также в: …» у повторяющегося товара не показываем
- (decision) Созданный из ячейки выпуск сразу добавляется в таблицу, даже если фильтр владельцев его исключает; при обновлении данных страницы (перезагрузке) он подчиняется фильтру и может пропасть
- (decision) В панели «Для кого считаем» — кнопки «Все регионы» и «Все заказы»
