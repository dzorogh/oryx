# Раскладка экрана

## Toolbar (белая `Card`, хлебные крошки над ней)

- Заголовок «Календарь выпусков».
- Фильтр прихода: «Свободно», регионы с галочкой «с заказами региона», заказы клиента.
- Фильтр «Завод» (коды).
- Строка «Считаем: Свободно + Север (с заказами) + OMS-12 · PLT-3».

## Колонки (слева направо)

| Колонка | Содержимое |
|---|---|
| Товар | Название и `PRD-N`; у повторяющегося товара пометка «также в: <категории>» |
| Код завода | см. `calculation-rules.md` |
| Остаток | см. `calculation-rules.md` |
| Месяцы | «Сен 2026», … — приход |
| Без срока | Приход без срока |

## Диапазон месяцев

- Начало: месяц самой ранней просрочки (незавершённый выпуск со сроком раньше текущего месяца). Если просрочки нет — текущий месяц.
- Конец: месяц самого позднего выпуска, но не раньше, чем текущий месяц + 5 (итого не меньше 6 месяцев, считая текущий).

## Строки

- Группа категории: название и число товаров, сворачивается кликом. Вложенность — по дереву категорий.
- Строка товара: одна на товар в каждой его категории. Пустые ячейки — пусто, не «0».

## Подсветка

- Колонка текущего месяца.
- Непустые ячейки прошедших месяцев (просрочка). Заголовки прошедших колонок не меняются.

## Быстрое создание (CAP-7)

- Кнопка «+» при наведении на ячейку товар × месяц, от текущего месяца и позже.
- Кнопки нет в прошедших месяцах, в «Остатке», «Без срока» и строках групп.
- Меню:
  - «Выпуск по PO-N — осталось разложить X шт» для каждого незакрытого заказа на производство, где у товара план больше, чем уже в выпусках.
  - «Новый заказ на производство…» — создаёт заказ и сразу черновик выпуска.
- Диалог: дата срока выпуска предзаполнена последним днём месяца ячейки и редактируется; количество.
  - Для нового заказа на производство — ещё завод, по умолчанию завод товара. Если у товара нет завода, поле пустое.
- После создания: страница перезагружает свой read-RPC и подсвечивает ячейку, куда попал выпуск.
