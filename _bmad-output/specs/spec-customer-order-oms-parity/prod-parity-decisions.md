# Прод-страница заказа OMS → карточка заказа клиента демо

Решение по каждому объекту прод-страницы `my.globaldrive.ru/app/oms/orders/:id` (my-front `src/modules/pim/modules/oms/pages/PageOmsOrder.vue`, my-back `app/Modules/OrderManagementSystem`, ветка `origin/main`). Демо — `/store/logistics/customer-orders/[id]`.

Значения: **Перенести** (строим, ссылка на CAP), **Заменено** (в демо уже есть своё решение, ничего не делаем), **Убрать** (не переносим).

## Шапка

| Объект прода | Решение | Демо / что строим |
|---|---|---|
| Номер и статус-тег | Заменено | Шапка-паспорт OMS-N и бейдж статуса |
| «Подтвердить получение» | Заменено | «Закрыть заказ клиента» |
| «Создать копию» | Перенести | CAP-3 |
| «Настройки валют» | Заменено | «Курсы» во вкладке «Деньги» |
| «Архивировать» / «Восстановить» | Убрать | Отмена и закрытие заказа |
| Статус оплаты заказа + срок | Перенести | CAP-4, вычисляется из платежей |
| Статус оплаты доставки | Перенести | CAP-5, сводка по платежам перемещений |
| Расчётный итог | Заменено | «Сумма заказа» в шапке |
| Товары (Σ шт) | Заменено | «Товаров» и «Отгружено» в мета |
| Склад | Заменено | «Источник»: завод или хаб |
| Тенант | Перенести | CAP-1: заказ привязан к региону, тенант выводится из региона |
| Создатель | Перенести | CAP-2 |
| Создан / Обновлён | Заменено | «Создан» + вкладка «История» |

## Статусы и сроки

| Объект прода | Решение | Демо / что строим |
|---|---|---|
| Лента 8 статусов (Draft … Done, два вида отмены) | Убрать | Enum заказа: черновик / открыт / закрыт / отменён; полоса этапов по документам |
| Плановая дата у каждого статуса | Убрать | Одна плановая дата «Ожидаемое окончание» |
| История статусов и плановых дат | Заменено | Универсальная «История» документа (статус + плановая дата) |
| Настройки статусов | Убрать | Жизненного цикла больше не настраиваем |

## Товары заказа

| Объект прода | Решение | Демо / что строим |
|---|---|---|
| Фото, название, ID, артикул | Заменено | Название и код PRD-N; артикула нет по соглашению |
| Цена (снимок) и «Итого» строки | Перенести | CAP-6 |
| «Макс. в конт.» | Перенести | CAP-7 |
| Правка количества (только в черновике) | Заменено | «Изменить количество» при любом статусе |
| Удаление строки, массовое удаление | Заменено | Удаление в диалоге строки |
| Поиск, пагинация по 10 | Убрать | — |
| «Добавить товар» | Заменено | Каталожная модалка заказа клиента |
| Подвал «Сумма товаров» / «Расчётный итог» | Заменено | Вкладка «Деньги» |
| Калькулятор загрузки (3D) | Перенести | CAP-8 |
