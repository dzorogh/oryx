# Денежные строки календаря

Дополняет раскладку `../spec-orders-calendar/table-layout.md`.

## Порядок групп

1. Товары по дереву категорий — как сейчас, в штуках.
2. «Платежи заводам» — одна строка на завод (`PLT-n`), у которого есть неоплаченные платежи или «Не распределено» ≠ 0.
3. «Поступления от клиентов» — одна строка на регион (код региона) с тем же условием.

Заголовки групп сворачиваются, как группы категорий.

## Ячейки

| Колонка | Товары | Денежные строки |
|---|---|---|
| Остаток | как сейчас | пусто |
| Не распределено | план PO без выпусков | Σ max(0, «Не распределено по платежам») неотменённых заказов строки |
| Без срока | выпуски без срока | пусто |
| Месяц / день | штуки выпусков | Σ платежей со статусом ≠ «Оплачен» у неотменённых заказов, срок в этом периоде |

- Все суммы — в валюте производств. Каждый платёж пересчитан по снимку своего заказа. Формат — сумма с кодом или символом валюты.
- Ячейка с хотя бы одним просроченным платежом подсвечена как просрочка.
- Наведение: список «заказ (ссылка) · срок · статус · сумма в валюте заказа → сумма в валюте производств». Для «Не распределено» — заказ, сумма заказа, распределено, остаток.
- Действий «+» у денежных строк нет: платежи вводятся в карточке заказа.

## Диапазон месяцев

Как в `table-layout.md`, но самый ранний месяц — минимум из просроченных выпусков и просроченных неоплаченных платежей неотменённых заказов (включая завершённые и закрытые). Самый поздний — максимум из сроков выпусков и платежей.

## Раскрытие месяца

- Клик по заголовку месяца раскрывает его во все дни (1…последний), повторный клик сворачивает. Раскрытыми могут быть несколько месяцев одновременно.
- Дни общие для всех групп. Значение свёрнутого месяца = сумма его дней.
- Состояние раскрытия не сохраняется в адрес и localStorage (как сворачивание категорий).

## Фильтры

Три кнопки в тулбаре. Иконка тёмная, если настройка отличается от умолчания. Каждая кнопка открывает свою панель справа, открыта одна за раз.

| Кнопка | Состав | Действует на |
|---|---|---|
| Выпуски | «Для кого считаем» (как сейчас) + завод | товарные строки |
| Платежи заводам | заводы, статусы «Запланирован» / «Выставлен счёт» | группа «Платежи заводам» |
| Поступления | регионы, заказы клиента, статусы | группа «Поступления от клиентов» |

Общего фильтра завода в тулбаре больше нет. Строка «Считаем: …» описывает только фильтр выпусков.
